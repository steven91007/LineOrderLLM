# src/handlers/liff_handler.py @ 9767874

Part of commit [9767874 feat: 增強 LIFF 整合與 Google Sheets 自動分組功能](../commits/629443e6d5434408dfa428992d9d863744cc971d55dad9889930d8ad1cb000aa.md) (A, +322/-0, kind: feature)

## Summary
New LIFFHandler that keeps in-memory edit sessions (uuid keyed, 2-hour expiry) holding a user's parsed orders; update_liff_session checks the user ID, validates orders (max 5, required receiver name/phone/address, at least one non-empty item, MM-DD date normalisation), writes them to Google Sheets via write_orders_batch if a client is present, and deletes the session. get_liff_url builds a liff.line.me URL with a clean liffRedirectUri (base_url + /liff/edit) and a sessionId query param, falling back to a relative web URL without a LIFF ID. setup_liff_routes registers /liff/edit, /liff/simple, GET/PUT /api/liff/orders/<session_id> and POST /api/liff/cleanup on the Flask app.
