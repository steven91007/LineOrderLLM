## Summary
New alternative Flask entry point that wires the LINE webhook to OrderHandler with liff_id and base_url, registers the LIFF routes via setup_liff_routes, and adds a home page, /health JSON, and a /liff/demo page that creates a demo LIFF session with sample order data. When run directly it starts a daemon thread that cleans expired LIFF sessions hourly and serves on port 5001. Reads GOOGLE_SHEET_ID / GOOGLE_CREDENTIALS_PATH (old names) and a DSPY_MODEL default of gpt-4o-mini.
