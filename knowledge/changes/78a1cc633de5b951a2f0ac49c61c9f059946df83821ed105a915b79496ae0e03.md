# src/utils/google_sheets_client.py @ 4175d13

Part of commit [4175d13 feat: enhance LIFF integration and Google Sheets auto-grouping](../commits/1cd5c2ac6f47082fca958be4f4a74906f22514b92c84f5367c6961890411393a.md) (M, +465/-11, kind: feature)

## Summary
Adds per-shipping-date worksheet routing: a new auto_organize_by_date flag, helpers to list/find sheets and create a YYYYMMDD_星期X sheet with a bold header row, and _determine_target_sheet which parses the order's shipping_date via time_utils (falling back to today when absent, or the default sheet when unparseable). append_order writes to the target sheet and returns target_sheet; append_multiple_orders groups rows by target sheet, appends per sheet and returns sheet_results/sheets_used, with the old single-sheet path kept as _append_multiple_orders_to_single_sheet. Timestamps now come from time_utils.get_current_time and the shipping-date column is stored as YYYY-MM-DD(星期X). Also adds get_sheets_summary, _is_date_sheet and organize_existing_orders_by_date to migrate legacy rows into date sheets.
