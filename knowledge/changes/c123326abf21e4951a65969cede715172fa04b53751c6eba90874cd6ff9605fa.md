# templates/liff_order_edit.html @ 4175d13

Part of commit [4175d13 feat: enhance LIFF integration and Google Sheets auto-grouping](../commits/1cd5c2ac6f47082fca958be4f4a74906f22514b92c84f5367c6961890411393a.md) (A, +438/-0, kind: feature)

## Summary
New Tailwind-styled LIFF editor page (Jinja placeholder for LIFF_ID). On load it saves the sessionId/session query param to localStorage, initialises the LIFF SDK, and if not logged in calls liff.login with a clean redirectUri and the session ID in the OAuth state; loadOrderData then resolves the session from the URL, state param, localStorage or hash, fetches GET /api/liff/orders/<id> and renders editable cards (receiver, address, dynamic items, MM-DD ship date, collapsible sender). Save validates required fields, PUTs the orders with the LIFF user ID, sends a confirmation text via liff.sendMessages and closes the window; if LIFF init fails it falls back to a test_user and loads data directly.
