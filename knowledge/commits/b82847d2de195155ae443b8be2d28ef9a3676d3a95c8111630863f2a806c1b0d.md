# 536f175 Add CI/CD to deploy the Discord bot to GCE

## Summary
Adds CI/CD for deploying the Discord bot to a GCE VM. A new GitHub Actions workflow runs pytest with uv on every push to master and, if it passes, SSHes into the VM (via appleboy/ssh-action with host/user/key from repository secrets) to git pull, uv sync, and restart the discord-order-bot systemd service. Also adds a systemd unit template and a Chinese setup guide covering VM bootstrap, deploy-key generation, GitHub secrets, and troubleshooting.

## Why
Automate deployment so that a push to master tests and then redeploys the bot without manual SSH work, as stated in the commit message.

## Risks
The deploy step runs `git pull` on the VM's checkout, which assumes a clean working tree and the correct branch. The remote script relies on `uv` being on PATH in a non-interactive shell, which broke and was fixed in bb0d143. The systemd unit contains YOUR_VM_USER placeholders that must be edited by hand. Any push to master with passing tests will restart the production bot.
