# ca84dfc Fix deploy workflow not finding the uv command

## Summary
Fixes the deploy job failing with 'uv: command not found' on the VM. The SSH script in .github/workflows/deploy.yml now exports PATH with ~/.local/bin and ~/.cargo/bin prepended before running uv sync.

## Why
appleboy/ssh-action runs a non-interactive shell that does not source ~/.bashrc, so the uv install location was not on PATH (per the commit message).

## Risks
None identified; it only widens PATH for the remote deploy script.

## Files
- `.github/workflows/deploy.yml` (M, +1/-0): Adds `export PATH="$HOME/.local/bin:$HOME/.cargo/bin:$PATH"` as the first line of the deploy job's remote SSH script. [note](../changes/413951232b5f9d2c57e6975ec62e934d43896a9654401af4ee7117bee6d6484e.md)
