# af0e68a feat: 完成 LINE Bot 智能訂單處理系統核心功能

## Summary
Implements the first end-to-end order flow. main.py now builds an OrderHandler from config.py and routes text messages and postback events to it; OrderHandler gates the '#訂單'/'#order' keyword behind an authorized-user check, keeps an in-memory per-user session, shows a buttons menu, sends the typed order text to OpenAIClient (chat completion with JSON response_format, temperature 0.1) and, after validation, displays a confirmation buttons template. Confirming generates an ORD-YYYYMMDD-XXXXXXXX id and appends a row through GoogleSheetsClient (service-account Sheets API, header row auto-created). Adds .env.example, a SETUP.md guide, and openai/google/gunicorn requirements.

## Why
Deliver the core product: let authorized LINE users paste free-form order text and have it parsed by GPT-4 and recorded in Google Sheets with a confirm step.

## Risks
Several reply strings use the two-character sequence backslash-n ("\\n") instead of a real newline, so users see literal '\n' in the prompt and error messages. Sessions live in a process-local dict, so they are lost on restart and do not work across multiple gunicorn workers. The confirmation summary is truncated to 300 characters for the LINE buttons template. GoogleSheetsClient hardcodes 'Sheet1' and sheetId 0 and swallows service-build errors by printing. Sender fields are mandatory in validation, which is relaxed in the next commit.
