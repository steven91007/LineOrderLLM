# 80f95c6 Add a single-page pipeline demo for interviews

## Summary
Adds pipeline-demo.html, a self-contained single-page demo for interviews with two tabs: an Overview (positioning, stat tiles, a flow diagram of the pipeline stages with unwired parts dashed, and real code excerpts per stage) and a Replay Theater that steps through a recorded run of the pipeline. The page embeds its data (recorded steps, model name, cases) and all CSS/JS inline, supports light/dark themes, an English/Chinese display toggle and a PII masking switch that hides phone-number-like text.

## Why
Interview/demo material, per the subject. The message states the replay data came from recording a real pipeline run through wrapped methods, and that all conversation content and personal details are fictional.

## Risks
Large static HTML added to the repo root; embedded DATA snapshot will drift from the real pipeline. Not part of the runtime application.
