# 3d3c5f0 Add automatic weekday-to-date conversion

## Summary
Adds a WeekdayConverter utility that maps Chinese/English weekday names (星期天, 週日, 禮拜天, 'sun', etc.) to the next occurrence of that weekday as MM-DD, also parses M/D, M-D, X月Y日 and M.D forms, and can append the Chinese weekday to an MM-DD string. UnifiedOrderParser._clean_date now calls WeekdayConverter.parse_shipping_date first and falls back to the previous logic; the prompt tells the model to convert weekday names to the next such date, and a few-shot example with '預計出貨日：星期天' is added. A manual test script covering the converter and end-to-end parsing is added.

## Why
The shop's order form asks for the shipping day as a weekday (e.g. 星期日/星期三), so '星期天' needs to become a concrete MM-DD date instead of null.

## Risks
Because WeekdayConverter.parse_shipping_date runs before the old YYYY-MM-DD branch, a full date like '2025-01-15' is matched by the (\d{1,2})[/-](\d{1,2}) regex as '25-01' instead of '01-15', regressing full-date input. The new few-shot example hard-codes '12-15' as the answer for '星期天', which teaches the model a fixed date rather than a relative one. Weekday matching does substring search over dictionary keys (including short English keys like 'sun', 'mon'), so unrelated text can trigger a conversion, and '週末' is mapped to Sunday. Conversion uses datetime.now() (local system time) rather than the network-time TimeUtils, and the resulting MM-DD drops the year, so 'today' rolls to next week and year boundaries are ambiguous. The example again contains apparent personal details.
