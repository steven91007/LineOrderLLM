# 0d840d2 init

## Summary
Initial commit of the LineOrderLLM repository: a minimal Flask app that verifies LINE webhook signatures on /callback and echoes text messages back, plus README notes on exposing the bot through ngrok and on why a bare EC2 IP cannot serve LINE webhooks (HTTPS requirement). Includes helper shell scripts for generating a self-signed certificate and for launching Flask plus ngrok, a uv-managed pyproject.toml, a pinned requirements.txt, a basic Python .gitignore and the generated uv.lock.

## Why
Bootstrap a LINE Messaging API bot skeleton and record the deployment constraints discovered while trying to host it on EC2.

## Risks
The setup script and the EC2 notes embed a concrete server IP. main.py listens on port 5000 while start_ngrok.sh tunnels port 5001, so the script as written does not expose the app. pyproject.toml declares fastapi/uvicorn/pydantic-settings that the Flask code does not use, and its versions disagree with the pins in requirements.txt.
