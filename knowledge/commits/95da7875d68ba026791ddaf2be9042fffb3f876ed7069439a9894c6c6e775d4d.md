# 922dc96 日期分頁加上出貨統計，並清理沒有來源的殘留分頁

## Summary
Adds a per-date shipping summary (packing list) beneath the order rows of every date tab, produced by the new shipping_summary module which parses the giftbox/family dropdown option strings in columns I/J into (spec, quantity, unit) and counts order rows per combination, reporting unparseable items instead of skipping them. SheetDateOrganizer now also detects stale date tabs that no longer have matching orders and clears them, and the CLI prints the summary lines, totals and stale-tab list in the preview.

## Why
The tabs needed a ready-made stocking list per delivery day; counting order rows (not unique addresses) matches how shipments are packed. Stale tabs were an existing bug: when an order's delivery date changed, the old date tab kept orphaned rows, contradicting the tabs' role as a projection of the master sheet.

## Risks
Existing sheet listing now happens even in dry-run mode, adding an API call. Stale tabs are cleared (not deleted) on --write, which is destructive if someone used them for anything else. Summary rows are appended to the same tab so anything reading the tab as pure order data must stop at the blank separator row. Only spec+count+unit prefixes like '20A 一盒' are recognized; new option formats will show as unparsed warnings.
