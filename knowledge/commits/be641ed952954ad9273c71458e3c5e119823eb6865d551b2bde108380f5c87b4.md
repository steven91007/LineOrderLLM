# 105dccf 新增訂單總表依配送日期拆分成日期分頁的功能

## Summary
Adds a tool that splits the order master sheet ('表單回覆 1') into one tab per delivery date inside the same spreadsheet. SheetDateOrganizer reads all rows, groups them by the normalized column-L delivery date (unparseable/blank dates go to a '未指定日期' tab), and on --write creates missing tabs with a frozen bold header and clears-then-rewrites each tab using RAW value input. A new organize_by_date.py CLI previews by default and writes with --write; FormSheetClient gains read_all_rows(); CONTEXT.md documents the '日期分頁' term.

## Why
Per the message: the date tabs are a projection of the master sheet, so rebuilding them wholesale on each run avoids duplicates and keeps them in sync after edits; RAW input is used because USER_ENTERED would turn phone numbers into numbers and drop the leading zero.

## Risks
Date tabs are fully overwritten every run, so manual edits there are lost by design. Tabs whose date no longer has any orders are not cleaned up in this version (addressed in a later commit). Date parsing supports a fixed set of formats; other spellings land in the undated tab.
