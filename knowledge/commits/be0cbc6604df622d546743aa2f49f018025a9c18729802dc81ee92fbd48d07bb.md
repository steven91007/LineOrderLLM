# 64f092f Translate docs, comments, logs and LLM prompts to English

## Summary
Translates the repository's prose to English: all Markdown docs (README, CLAUDE.md, CONTEXT.md, setup and deploy guides), code comments, docstrings, developer-facing log/print messages, config-file comments, and the LLM prompt instructions of the DSPy signatures, the OpenAI client and the JSON schemas. Chinese that the program depends on is kept: LINE/Discord/LIFF text shown to customers and staff, Google Form/Sheet option strings and headers, item names, address data, regexes, keyword lists, test fixtures and few-shot data. CLAUDE.md gains a Language section recording this rule.

## Why
The owner asked for the codebase, docs and commit history to be in English; functional strings have to stay Chinese because they are matched against data or shown to Chinese-speaking customers and staff.

## Risks
The Python AST is unchanged apart from string literals, but the prompt text the LLM sees changed (signature instructions, describe_options labels), so parsing quality may shift slightly; two prompt rules were added to keep staff-facing `issues`/`error_message` output in Traditional Chinese. Developer-facing log and diagnostic messages are now English.
