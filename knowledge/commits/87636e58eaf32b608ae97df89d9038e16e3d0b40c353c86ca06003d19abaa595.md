# 76e64b3 改用 uv 管理依賴，Python 釘在 3.13

## Summary
Pins the project to Python 3.13 via a new .python-version, trims unused dependencies (fastapi, google, httpx, uvicorn) while adding jsonschema and discord-py to pyproject.toml, and adds a [tool.pytest.ini_options] block setting pythonpath=['.'] and testpaths=['tests']. uv.lock is regenerated accordingly.

## Why
The repo already had pyproject.toml and uv.lock but no uv setup or .venv; without a pin uv chose Python 3.14, for which the locked tiktoken 0.9.0 has no wheel and would require a Rust source build. The pytest config lets tests import src and config from the repo root.

## Risks
Removing fastapi/uvicorn/httpx/google breaks anything still importing them (nothing in the diff shows usage, but this was not verified). discord-py becomes a required dependency. uv.lock hunks were omitted, so exact version changes are unknown.
