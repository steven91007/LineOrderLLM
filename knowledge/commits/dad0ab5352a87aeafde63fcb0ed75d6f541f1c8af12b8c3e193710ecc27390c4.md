# 5ae8580 Add alternating row colors to order rows in date sheets

## Summary
Adds alternating row banding (light orange on even rows, white on odd) to the order rows of every date tab. _existing_sheet_names() becomes _existing_sheets(), returning sheetId and existing bandedRange ids per tab; _create_sheet() returns the same metadata; a new _apply_banding() deletes old bandings and adds one sized to the current row count (A:L, starting after the header), and stale tabs get their banding removed.

## Why
Readability for older users scanning rows across the sheet. Because tabs are rebuilt with a varying row count each run, bandings must be deleted and recreated so they neither overlap the summary block nor leave empty coloured rows.

## Risks
Adds one batchUpdate per tab per run. Any pre-existing bandings on those tabs (including manually added ones) are deleted. The spreadsheet get now uses a fields mask, so any other metadata previously fetched is no longer available.
