# 2c8b729 Langfuse v4 ready: upgrade the SDK to 4.15.6 and add offline tests for the tracing module

## Summary
Prepares the repository for Langfuse v4: upgrades the Python SDK from 4.14.4 to 4.15.6 and the OpenInference DSPy instrumentor from 0.1.39 to 0.1.45 in pyproject.toml and uv.lock, adds an offline test suite for src/utils/langfuse_tracing.py that captures spans with an in-memory OpenTelemetry exporter, and documents the optional LANGFUSE_TRACING_ENVIRONMENT / LANGFUSE_RELEASE settings in .env.example. No tracing code changed: the existing start_as_current_observation + propagate_attributes pattern is already the v4 (observations-first) shape.

## Why
Langfuse Cloud removes legacy ingestion and trace-level features on 2026-11-16; Python SDK >= 4.7.0 sends the v4 real-time ingestion header, and a code audit found no deprecated calls, so the remaining work was pinning current versions and adding verification that session ids reach every observation.

## Risks
The tests bypass auth_check and never contact a Langfuse server, so backend ingestion is not verified; send representative traces to a non-production project before relying on the upgrade. The chat-log parse trace (the cost-bearing DSPy generations) deliberately carries no session id because one parse yields many orders, so per-order session cost in Langfuse excludes LLM cost. openinference-instrumentation 0.1.66 is a transitive bump; DSPy is still 2.6.27.
