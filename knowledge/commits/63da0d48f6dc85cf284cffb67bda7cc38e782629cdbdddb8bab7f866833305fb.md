# 0dd9b50 Add gitkb: a git-history knowledge base tool and the /gitkb command

## Summary
Ports the gitkb git-history knowledge base from the Jobseekers project into this repository as a top-level gitkb/ package with its CLI (pending, import, build, rebuild-index, show, search, log, history), an offline end-to-end test, a /gitkb slash command for Claude Code, an agent guide under docs/agents/, and short README, CLAUDE.md and .env.example entries. The slash command is adapted to run through `uv run` because this project pins Python 3.13 with uv. .gitignore now tracks .claude/commands/ while still ignoring the rest of .claude/, and ignores the SQLite index and the pending/summaries scratch files.

## Why
So agents and people can ask why code is the way it is (per-file history and full-text search over commit summaries) before changing it, using the same tool and note format as the sibling Jobseekers project, which also lets jobseekers-mcp's gitkb_* tools point at this repository via GITKB_REPO.

## Risks
The package is an unmodified copy of Jobseekers' gitkb, so fixes must be mirrored between the two repositories by hand. python-dotenv is only present transitively (via pydantic-settings); config.py degrades to no .env loading if it disappears. The .gitignore change to `.claude/*` means any other files under .claude/ stay untracked, but a future `.claude/settings.local.json` would still be ignored as intended. knowledge/index.db is not committed, so a fresh clone must run `rebuild-index` (or the MCP server's auto-rebuild) before search/show work.
