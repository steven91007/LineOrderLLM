# 6b02be3 Fix NameError in organize() and add a test that catches it

## Summary
Fixes a NameError in SheetDateOrganizer.organize(): two call sites still referenced the old private name _is_past_sheet after it had been renamed to the public is_past_sheet, so the /organize command crashed as soon as it computed locked or stale sheets. Adds five end-to-end tests in tests/test_sheet_locking.py that drive organize(dry_run=True) through a fake sheet client (no Google credentials) and assert the locked-sheet and stale-sheet results. Also drops unused imports in discord_views.py and test_offday_orders.py.

## Why
The commit message explains the rename in the previous commit was incomplete and the bug slipped through because no test exercised organize() itself (it needed a live Google client). The new tests were verified to fail with the bug reintroduced.

## Risks
Low; the fix restores intended behaviour. The tests construct SheetDateOrganizer via __new__ and monkey-patch _existing_sheets, so they are coupled to the class's internal attribute names (client, service, sheet_id, source_sheet, _existing_sheets) and will need updating if those change. The same fix was made independently on origin/master (1e454fe), which later merged cleanly.
